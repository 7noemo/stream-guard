# Stream Guard

直播画面风险自动遮挡工具。后台采集画面 → 视觉风险评分 → 自动切换 OBS 模糊滤镜，画面恢复正常后自动移除遮挡。带图形界面，无需接触代码。

## 功能

- **自动遮挡**：后台持续检测画面，命中风险时自动开启模糊滤镜，画面恢复后自动移除
- **多种画面来源**：OBS 节目场景（推荐）/ OBS 指定源 / 窗口跟踪 / 屏幕区域，界面下拉框切换
- **防闪烁**：连续帧确认 + 滞回阈值 + 最短保持时间，避免遮挡来回开关
- **手动控制**：热键切换 / 一键紧急遮挡 / 恢复自动判定，另有界面按钮
- **OBS 集成**：一键创建模糊滤镜、连接测试、自动列出可用场景与源
- **多输出模式**：OBS 滤镜开关 / OBS 场景切换 / 抖音直播伴侣快捷键（支持组合键、双键/单键模式、热键冲突检测）/ 干跑模式
- **直播伴侣工具**：一键生成遮挡图片素材、分步接入向导、无 API 也能自动遮挡
- **直播统计**：遮挡次数、累计遮挡时长、最近触发时间
- **配置管理**：图形化编辑、导入导出、诊断报告（密码自动打码）
- **托盘驻留**（Windows）：关闭窗口缩到系统托盘，右键可紧急遮挡或退出

## 画面来源（重要）

界面「画面来源」下拉框决定检测哪一路画面：

| 来源 | 说明 | 适用场景 |
|------|------|----------|
| `obs_scene`（默认，推荐） | 通过 OBS WebSocket 取当前节目场景的最终合成画面，含所有滤镜与叠加层 | 用 OBS 直播，检测内容 = 观众所见，不受弹窗/切窗口/最小化影响 |
| `obs_source` | 取 OBS 中某个指定源（如游戏捕获）的画面 | 只想检测游戏画面本身 |
| `window` | 按窗口标题跟踪其屏幕矩形抓屏 | 无 OBS、需锁定某个窗口；DX 全屏游戏请用无边框窗口模式 |
| `screen` | 抓整屏或框选区域（mss / dxcam） | 直播伴侣等无 API 的软件，配合框选排除伴侣界面 |

为什么推荐 `obs_scene`：它检测的就是推流出去的那一帧，和平台审核看到的内容一致；而且不依赖屏幕可见性——你切出去看弹幕、窗口被挡住、甚至最小化 OBS，检测照常进行。前提是 OBS 已开启 WebSocket 服务。

## 快速开始

### macOS

直接下载 Release 中的 dmg，安装后首次运行按需授权：

1. **辅助功能权限**（全局热键）：系统设置 → 隐私与安全性 → 辅助功能 → 勾选 Stream Guard
2. **屏幕录制权限**（仅当选 `screen` / `window` 画面来源时需要）：同页 → 屏幕录制 → 勾选 Stream Guard
3. 授权后重启应用

使用默认的 `obs_scene` 来源时**不需要**屏幕录制权限，画面直接来自 OBS。

从源码运行：

```bash
python3 -m pip install -r requirements.txt
python3 app.py
```

打包 macOS 应用（推荐用脚本，固定输出目录并在完成后清理中间产物）：

```bash
python3 -m pip install pyinstaller
./build-mac.sh
# 产物: StreamGuard-macOS-arm64.dmg
# 脚本会提示中间产物 dist-mac/ 与 build-mac/ 的位置，可按需删除释放约 130MB
```

或手动打包：

```bash
python3 -m PyInstaller stream-guard-mac.spec --noconfirm --distpath dist-mac --workpath build-mac
```

> PyInstaller 的中间产物（`build*/`、`dist*/`）体积很大（每份约 130MB）且可随时再生。
> 反复打包后若磁盘紧张，直接删除这些目录即可，不影响源码和运行。

> macOS 版不启用系统托盘，关闭窗口即退出。全局热键依赖辅助功能权限，未授权时请用界面按钮。

### Windows

**方式 A · 本地构建**

1. 安装 Python 3.11 64 位
2. 把整个项目文件夹复制到 Windows
3. 双击 `build.bat`，等待依赖安装和打包完成
4. 产物为 `dist\StreamGuard.exe`，把 `config.json` 放在 exe 同目录

**方式 B · GitHub Actions**

把代码推到仓库，在 Actions 页手动触发 `Build Stream Guard Windows EXE`，完成后从 Artifacts 下载。

**开发模式运行**：双击 `run.bat`。

## OBS 配置

1. OBS → 工具 → WebSocket 服务器设置 → 启用，设置端口（默认 4455）和密码
2. 在界面「输出与热键」区填入地址、端口、密码
3. 填好捕获源名称（可点「测试连接」查看可用源列表）
4. 点「一键创建模糊滤镜」，自动在 OBS 中建好名为 `StreamGuard_Blur` 的模糊滤镜并设为禁用
5. 输出方式保持 `obs_filter`，点「开始监控」

也可以用 `obs_scene` 模式：提前准备一个全屏遮挡场景，在配置里填正常场景和遮挡场景名。

### 抖音直播伴侣（无 API 方案）

直播伴侣没有开放接口，但有**自定义快捷键**。原理是：在伴侣里放一张遮挡图片素材并绑定显示/隐藏热键，Stream Guard 检测到风险时模拟按下这些键，把遮挡图层盖到画面上，恢复后自动撤掉。界面点「配置向导」有分步图文说明。

**配置步骤：**

1. 在程序里点「生成遮挡素材」，生成几张 PNG（磨砂/深色/马赛克/纯色）。
2. 直播伴侣「添加素材 → 图片」选中一张，拉伸铺满画布并拖到**最上层**，平时保持**隐藏**。
3. 直播伴侣左下角「直播设置 → 快捷键」，给该素材的**显示**和**隐藏**各绑定一个冷门组合键，例如 `Ctrl+Shift+9`（显示）和 `Ctrl+Shift+0`（隐藏）。
   - 避开 `Ctrl+1`~`Ctrl+9`（被场景切换占用）
   - 避开游戏本身和 Stream Guard 手动热键占用的键
4. 程序里输出方式选 `companion`，按键模式选 `dual`（显示/隐藏分开，最稳），填入与上一步**完全一致**的热键。填错或冲突界面会红字提示。
5. 画面来源选 `screen`（框选游戏区域，排除伴侣界面和弹幕）或 `window`（跟踪游戏窗口）。
6. 点「开始监控」先测试一次，确认伴侣画面会自动盖遮挡、恢复后自动撤掉，再正式开播。

**按键模式：**

| 模式 | 说明 |
|------|------|
| `dual` | 显示键 / 隐藏键分开，状态确定，推荐 |
| `toggle` | 单键切换，需在伴侣侧把该键设为"切换显示/隐藏"语义 |

**关键提醒：**

- 模拟按键作用于**当前焦点窗口**。直播伴侣的快捷键通常是全局生效的（切到游戏也能触发）；若你设置的键只在伴侣窗口内生效，就让游戏用无边框窗口模式、不要让游戏独占焦点。
- Stream Guard 与直播伴侣若以不同权限运行（一个管理员、一个普通），按键可能发不进去——两者请用同一权限级别运行。
- 退出程序时会自动发"隐藏"键复位，不会把遮挡图层留在直播画面上。但程序被强制结束（任务管理器 kill）时来不及复位，开播前请确认伴侣画面已恢复正常。

**更稳的替代方案**：抖音官方已关闭 OBS 推流模式，但支持把 OBS 虚拟摄像机作为摄像头素材接入伴侣。这样检测走 OBS WebSocket（`obs_scene` 来源）、遮挡走 OBS 滤镜（`obs_filter` 输出），比模拟按键可靠得多。代价是画面需经 OBS 中转一次。

## 性能与资源占用

程序按直播长时间运行设计，做了这些优化：

- **采集即降采样**：抓屏后立刻缩到检测尺寸（默认 640×360，可在「截图分辨率」改）。1920×1080 全尺寸不再流入检测链路，像素量减少约 9 倍，显著降低 CPU 与内存分配。OBS 路径直接按该尺寸截图。
- **静止帧跳过**（模型后端）：画面几乎不变时复用上一次的风险分，跳过昂贵的模型推理；画面一变立即重算，长期静止也有强制重算上限。静止场景下模型后端 CPU/GPU 占用大幅下降。
- **模型资源限制**：`opennsfx2`（TensorFlow）开启显存按需增长、限制线程；`CLIP`（PyTorch）用推理模式并限制线程数（配置 `detector.threads`，默认 2），避免抢游戏资源。停止监控时释放模型。
- **内存有界**：日志面板、事件队列、遮挡统计都有上限，长时间直播内存不会持续增长。
- **检测后端开销排序**：`heuristic`（纯数值，最低）→ `opennsfw2` → `CLIP`（最高）。追求低占用用 heuristic，追求准确度用模型后端。

**降低占用的建议**：检测帧率按需要调（8fps 够用，无需拉满）；抓屏区域只框游戏画面；模型后端把 `threads` 设为 1~2；游戏用无边框窗口模式配合 dxcam 后端。

## 检测后端

| 后端 | 依赖 | 说明 |
|------|------|------|
| `heuristic` | 无 | 肤色比例启发式，开箱即用，**误报率高**，仅建议演示 |
| `mock` | 无 | 按预设分数循环，仅用于测试流程和状态机 |
| `opennsfw2` | `pip install opennsfw2` | 本地 NSFW 模型，对写实内容较准，对 3D 游戏角色误报偏高 |
| `clip` | `pip install torch transformers` | 零样本分类，可通过提示词适配游戏画面，体积大 |

正式使用前建议用真实游戏画面样本校准阈值：

```bash
# 样本文件名以 pos_ 开头视为风险样本，neg_ 开头为安全样本
python3 tools/calibrate.py ./samples
```

工具会输出分数分布和建议阈值。

## 热键

| 按键 | 功能 |
|------|------|
| F9 | 手动切换遮挡状态 |
| F10 | 紧急强制遮挡 |
| F11 | 恢复自动判定 |

按键可在界面中修改，支持单键和组合键写法：`f9`、`ctrl+1`、`ctrl+shift+f9`、`alt+x` 等（分隔符可用 `+` 或空格，修饰键别名 `control/win/super/meta` 均可）。程序自己模拟的按键（直播伴侣输出）不会误触发这些手动热键。macOS 上全局热键需要辅助功能权限。

## 主要参数

- **触发阈值 / 解除阈值**：风险分的门限，解除阈值应低于触发阈值（滞回）
- **连续命中 / 解除帧数**：连续多少帧满足条件才切换状态
- **最短保持时间**：遮挡后至少保持多少秒才允许解除
- **检测帧率**：每秒检测次数，越高反应越快、CPU 占用越大
- **抓屏后端**：Windows 全屏独占游戏下优先用 `dxcam`（DXGI），`mss` 作为兜底；建议游戏设为无边框窗口模式

## 注意事项

- 这是辅助工具，不是保险。模型误判可能导致该遮的没遮、不该遮的狂遮，关键场景仍需人工值守。
- 技术处理不能解决「平台是否允许直播该游戏」的政策问题，开播前请确认平台规则。
- macOS 打包应用未签名，首次打开可能需要右键 → 打开，或在系统设置中允许。
